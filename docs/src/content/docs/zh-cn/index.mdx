`inplace-init` 是一个兼容 `no_std` 的 Rust 库，可在调用方提供的存储中直接构造值。初始化器既可以写入完整值，也可以逐字段构造结构体。初始化成功后会返回凭证，独占访问目标值并负责析构。

普通值使用可移动初始化 API。如果构造过程依赖值的最终地址，例如自引用类型，则使用固定地址初始化 API。派生宏和初始化宏会生成字段投影及类型状态代码。

## 库提供的保证

- `InitSlot` 表示一个独占且尚未初始化的目标位置。
- 初始化成功后会返回 `InitReceipt`，由它承担目标值的析构责任。
- 结构体初始化宏会把字段投影到最终目标位置；后续字段失败时，已经构造的字段会被清理。
- 固定地址初始化使用单独的模式和凭证 API，使值能够在最终地址构造，并通过 `Pin` 访问。

默认 feature 集兼容 `no_std`，且不启用分配器。启用 `alloc` 可使用 Box 初始化和基于分配的集合默认值；启用 `std` 可为 `HashMap` 与 `HashSet` 提供默认初始化。
